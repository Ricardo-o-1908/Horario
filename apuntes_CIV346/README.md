# Apuntes Hidráulica Aplicada (CIV-346) en LaTeX

Transcripción de las clases 01–12 (Hidrología subterránea, Aguas subterráneas y
Drenaje superficial). Todas las figuras están dibujadas en LaTeX (TikZ/PGFPlots),
sin imágenes externas.

- `main.tex`: preámbulo (paquetes, colores, cajas de fórmulas) e índice.
- `clases/claseXX.tex`: contenido de cada clase (se pueden copiar/pegar por separado,
  siempre junto con el preámbulo de `main.tex`).
- `apuntes_CIV346.pdf`: versión compilada.

Compilar: `pdflatex main.tex` (dos veces para el índice).
